# UX: daftar odamiga mos

## Printsiplar

1. Birinchi ekran = **Savdo** (dashboard emas).  
2. Katta tugma, kam matn.  
3. Oddiy o‘zbekcha atamalar.  
4. Xato = nima qilish kerakligi.  
5. Barcode yordamchi; nom bilan ham ishlasin.  
6. Nakladnoy majburiy emas — tezkor yo‘l ko‘rinadigan bo‘lsin.

## Atamalar

| Ichki / eski | Do‘kon tili |
|--------------|-------------|
| POS | Savdo |
| Catalog | Tovarlar |
| Inventory / Stocktake | Ombor / Hisob-kitob |
| Debt | Qarz / Nasiya |
| Shift | Smena |
| Void | Bekor qilish |
| Refund | Qaytarish |
| Supplier | Yetkazib beruvchi |
| Tendered / Change | Berilgan / Qaytim |
| Nakladnoy (draft) | Yig‘ish ro‘yxati / Nakladnoy |

## Kassir oqimi

1. PIN → (kerak bo‘lsa) smena ochish  
2. Savdo: qidiruv / skaner → savat  
3. Ulgurji kerak bo‘lsa — tanlash  
4. Yig‘ish kerak → **Nakladnoy chop**; aks holda **To‘lash**  
5. Naqdda **Berilgan** → **Qaytim** ko‘rinadi  
6. Nasiya bo‘lsa ism/telefon/muddat  

## Admin menyu (sodda)
